# Abhinesh Portfolio — OpenCode Design Package

## Files

- `CORE_IDEA.md` — strategic foundation, positioning and story.
- `OPENCODE_MASTER_BRIEF.md` — full design + engineering implementation brief.
- `HERO_STORYBOARD.md` — exact 3–4 scroll hero narrative.

## Recommended instruction to OpenCode

> Read all three files before modifying the project. Treat them as the creative and implementation source of truth. First inspect the existing codebase and Supabase integration. Do not start by rewriting the application. Understand the architecture, preserve working functionality and then implement the documented experience.

## North star

# I GO WHERE THE PROBLEM IS.

The portfolio should make the visitor think:

> **Give this person a difficult problem and see what he builds.**

## Critical constraint

This is a portfolio. The storytelling should create context and curiosity, but **real work must appear by approximately the third/fourth scroll**.
